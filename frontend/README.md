# Frontend de gestão de perfumes

React + Vite + JavaScript + Axios + React Router + Bootstrap 5.

Execute npm ci e npm run dev neste diretório. Interface: http://localhost:5173. API padrão: http://localhost:5080/api. O arquivo .env.example documenta VITE_API_URL. Build: npm run build.

Páginas: dashboard de cadastros, fornecedores, insumos e produtos fornecidos. Inclui busca, paginação, status, formulários, alteração de preço e histórico com vigências. Quantidades normalizadas e custo vêm do backend.

Build validado. Integração persistida aguarda LocalDB funcionando; consulte README da raiz.

Referências: https://vite.dev/guide/ e https://reactrouter.com/start/declarative/routing
